Internship Management System
A collaborative student project built to simplify internship applications for students and companies.

Overview
This project is a full‑stack web application created by a group of students as part of an academic assignment. The system provides a simple and organized way for students to browse and apply for internships, while companies can post opportunities and manage applications.

The goal was to understand how real‑world platforms work by building a basic version with separate user roles, a database, and a functional interface.

Key Features
Student Side
Create an account and log in
View available internships
Apply for internships
Track application status
Update profile and upload CV

Company Side
Register and log in
Post internships
Edit or delete postings
View applications
Update application status

General System Features
Role‑based login (student/company)
Secure password hashing
REST‑style backend routes
MySQL database for storing all records
